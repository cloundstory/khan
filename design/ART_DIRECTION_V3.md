# คั่น — Art Direction v3

วันที่ 10 กันยายน 2026
สถานะ: draft จาก reference ใน `art direction/`

## ทิศทางหลัก

คั่นควรกลับมาเป็นแอปภาพประกอบ 2D แบบหนังสือภาพและสมุดบันทึกส่วนตัว โดยใช้เส้นหมึกที่มีน้ำหนักไม่สม่ำเสมอ พื้นกระดาษอุ่น พื้นผิวพิมพ์เก่า และสีแต้มที่จำกัด งานต้องรู้สึกเหมือนฉากในห้องอ่านหนังสือที่วาดด้วยมือ แล้วนำมาประกอบกับ UI ที่ตอบสนองได้จริง

ภาพใหม่ในโฟลเดอร์ `art direction/` มีทิศทางเดียวกันทั้ง desktop และ mobile จึงควรเป็น source of truth แทน prototype 3D ในรอบนี้

## สิ่งที่ภาพ reference บอกเรา

- ภาพหลักต้องเป็นห้องอ่านหนังสือที่อบอุ่น มีเก้าอี้ ชั้นหนังสือ โคมไฟ ต้นไม้ พรม แมว และกองหนังสือ
- เส้นดำและ texture กระดาษเป็นตัวเชื่อมทุกวัตถุเข้าด้วยกัน แม้สีของหนังสือจะต่างกัน
- สีไม่ได้ถูกลดจนเป็นขาวดำ แต่ใช้สีหม่นและสีดินอย่างมีลำดับ: เขียวเข้ม น้ำเงินหม่น ส้มอิฐ น้ำตาลไม้ และครีมกระดาษ
- Desktop ใช้ฉากกว้างเป็นพระเอก ขณะที่ mobile ใช้ฉากแนวตั้งและแบ่งสถานะเป็นสามจุดที่อ่านได้ทันที
- ตัวละครในภาพ mobile เป็นทางเลือกของบรรยากาศ ไม่ควรเป็นเงื่อนไขของแอป เพราะเก้าอี้ต้องยังเป็นที่ของผู้ใช้
- ภาพเก้าอี้แยกชิ้นเหมาะกับการเป็น asset 2D โปร่งใส มี texture และขอบที่ไม่เรียบสนิท ไม่จำเป็นต้องทำเป็นโมเดล 3D

## ระบบภาพ

### สี

| บทบาท | ค่าเริ่มต้น | การใช้ |
|---|---|---|
| กระดาษ | `#F5F0E4` | พื้นหลักและพื้นที่ว่าง |
| หมึก | `#282825` | เส้น ตัวอักษร และเงาหลัก |
| เขียวห้อง | `#34483D` | เก้าอี้ ต้นไม้ และจุดนำสายตา |
| น้ำเงินหม่น | `#3E5365` | ปกหรือหมอนที่ถูกเลือก |
| ส้มอิฐ | `#B96343` | สถานะ active, bookmark, ปกบางเล่ม |
| น้ำตาลไม้ | `#754A2E` | ชั้น โต๊ะ ขาเก้าอี้ และกรอบ |

สีจริงของปกหนังสือคงไว้ในพื้นที่รายละเอียดหรือเล่มที่กำลังเลือก ส่วนหนังสือจำนวนมากในฉากควรลด saturation และใช้โทนจากปกเดิม เพื่อไม่ให้ห้องกลายเป็นชั้นสีที่แย่งความสนใจจากการอ่าน

### เส้นและพื้นผิว

- เส้น outline มีน้ำหนักประมาณ 1–3 px ตามระยะและความสำคัญของวัตถุ
- ใช้ crosshatch, stipple, dry-brush และรอยพิมพ์เหลื่อมเล็กน้อยเพื่อสร้าง handcraft
- พื้นผิวควรอยู่ใน asset หรือ texture layer ไม่ใช้ CSS noise หนักทั่วทั้งหน้า
- ขอบภาพควรมีความไม่สม่ำเสมอเล็กน้อย แต่ hit area และตัวอักษรต้องคมและอ่านง่าย
- เงานุ่มและแบนกว่าภาพ 3D ใช้ hatch ช่วยบอกน้ำหนักแทน realistic shadow

## องค์ประกอบตามหน้าจอ

### Desktop Home

ใช้ฉากห้องกว้างหนึ่งภาพเป็น hero ประมาณ 60–70% ของพื้นที่ด้านบน แบรนด์และ navigation อยู่บนกระดาษด้านบน ชื่อสถานะอยู่ใต้พื้นที่ที่กดได้ ไม่วาง panel จำนวนมากทับภาพ

โครงองค์ประกอบจากซ้ายไปขวา:

1. กองหนังสือ: `pile` หนังสือที่ยังรออ่าน
2. มุมอ่าน: `desk` หนังสือที่กำลังอ่าน เก้าอี้ว่าง โคมไฟ และโต๊ะข้าง
3. ชั้นหนังสือ: `shelf` หนังสือที่อ่านจบแล้ว

แมวและต้นไม้ทำหน้าที่สร้างจังหวะสายตา ไม่ควรเป็นปุ่มหลัก หากต้องกดให้มีบทบาทรอง เช่น เปิดรายละเอียดบรรยากาศหรือสลับ motion

### Mobile Home

ใช้ภาพแนวตั้งที่จัดองค์ประกอบใหม่ ไม่ย่อภาพ desktop ลงมา แบรนด์อยู่ด้านบน ฉากหลักอยู่กลางจอ และตัวเลือกสามสถานะอยู่ใต้ภาพเป็นภาพวัตถุขนาดใหญ่ที่แตะง่าย

bottom navigation และปุ่มเพิ่มหนังสือเป็น UI จริง ไม่ฝังในภาพ เพื่อให้ใช้งานด้วย screen reader, keyboard และ localization ได้

## หนังสือปกจริงกับงานภาพ

ปกจริงอยู่ร่วมกับ art direction ได้ หากแบ่งหน้าที่ชัดเจน:

- ฉากรวม: แสดงสันและขอบหนังสือแบบวาดมือ โดยใช้สีหลักจากปกจริงและวางชื่อเมื่อพื้นที่พอ
- หนังสือที่เลือกหรือกำลังอ่าน: แสดงภาพปกจริงเป็นชิ้นเด่นบนโต๊ะหรือในรายละเอียด
- ชั้นหนังสือ: แสดงสันของหนังสือจริงที่อ่านจบแล้ว ไม่ใช้เล่มตกแต่งเพื่อเติมพื้นที่
- รายการและ search: แสดงปกจริงเต็มใบพร้อมชื่อ ผู้เขียน และสถานะ

วิธีนี้รักษาความเป็นงานภาพของห้อง และยังทำให้ผู้ใช้รู้ว่าเล่มที่เห็นคือเล่มจริงของตนเอง แต่ละวัตถุยังผูกกับ `Book.id` เดียวเสมอ

## Motion language

ใช้ motion แบบภาพประกอบหลายเลเยอร์ ไม่ใช้กล้องหมุนหรือ perspective แบบ 3D:

- แมว: หายใจช้า ๆ และกระดิกหางนาน ๆ ครั้ง
- ใบไม้: sway ไม่เกิน 1–2 องศา คนละ phase ต่อกระถาง
- โคมไฟ: ค่อย ๆ เพิ่ม glow เมื่อเข้า `desk`
- หนังสือ: ขยับสั้น ๆ ตอนย้ายสถานะ แล้วหยุดนิ่ง
- ฉาก: parallax เบามากระหว่างพื้น ผนัง และวัตถุหน้า ไม่เกิน 4–8 px
- reduced motion: ใช้ภาพนิ่งและตัด parallax กับ breathing ออก

ทุก animation ต้องหยุดเมื่อแท็บไม่แสดง และไม่ทำให้ข้อความหรือปุ่มสั่นตามภาพ

## โครงสร้าง asset ที่แนะนำ

สร้างจากภาพแยกชิ้นแทนโมเดล 3D:

- `room-base-desktop` และ `room-base-mobile`
- `shelf`
- `armchair`
- `side-table`
- `lamp`
- `cat-body`, `cat-tail`
- `plant-pot`, `plant-leaves`
- `pile-anchor`, `desk-anchor`, `shelf-anchor`
- `book-cover` และ `book-spine` ที่สร้างจาก `Book` แต่ละเล่ม
- `evidence-board` และกระดาษโน้ตเป็น UI/asset แยก

ภาพ master เก็บเป็น PNG โปร่งใสหรือ SVG ตามลักษณะงาน ส่วนตำแหน่ง ป้าย สถานะ ปุ่ม และข้อมูลหนังสือสร้างด้วยโค้ด

## สิ่งที่จะพักไว้

`src/design/Diorama.tsx`, `src/design/BookStudy.tsx`, `src/design/roomLayout.ts` และโมเดล Blender เก้าอี้ยังเก็บไว้เป็น exploration branch เพื่อไม่ให้สูญงาน แต่ไม่ควรเป็น visual runtime หลักในเฟส 2D นี้ จนกว่าจะมีเหตุผลกลับมาใช้ 3D อีกครั้ง

## ลำดับทำงานใหม่

1. ล็อก palette, line weight, texture และ composition จาก reference ชุดนี้
2. ทำ asset 2D โปร่งใสของเก้าอี้ กองหนังสือ ชั้น โต๊ะ โคม แมว และต้นไม้
3. สร้าง Home shell desktop/mobile ให้ตำแหน่งและพื้นที่กดตรงกับภาพ reference
4. ผูกหนังสือจริงเข้ากับ anchor ของ `pile`, `desk`, `shelf`
5. เพิ่ม motion แบบ layer และ reduced-motion fallback
6. ต่อ timer กับ evidence board บนโต๊ะอ่าน
7. ทดสอบห้องว่าง, 1 เล่ม, หลายเล่ม, จำนวนมาก, หนังสือไม่มีปก, mobile, keyboard และ offline

## เกณฑ์ตัดสินภาพ

ภาพใหม่ผ่านเมื่อผู้ใช้เห็นได้ทันทีว่า “นี่คือห้องของฉันที่กำลังอ่านหนังสือ” โดยไม่ต้องอธิบาย 3D, engine หรือระบบสถานะ และเมื่อเพิ่มหนังสือจริง ห้องต้องเปลี่ยนจากข้อมูลของผู้ใช้ ไม่ใช่จากเล่มตกแต่งในภาพต้นแบบ
