# คั่น — Home concept art v4

ไฟล์ภาพ: `public/concept/home-v4.png`

## เป้าหมายของภาพ

ภาพนี้ใช้เป็นฉาก 2D หลักของ `?concept-lab` โดยให้ห้องทำหน้าที่เป็นบรรยากาศ และให้หนังสือหนึ่งเล่มเป็นพระเอกตรงกลางภาพเมื่อเปิด viewer แบบ 3D

- ลด contrast ของห้องรอบหนังสือ เพื่อให้วัตถุที่ถูกเลือกอ่านง่ายขึ้น
- เพิ่ม evidence board บนผนัง พร้อมการ์ดและเส้นเชื่อมเบาะแส
- เพิ่มนาฬิกาหน้าปล่อยว่าง ไม่มีตัวเลขและไม่มีเข็ม เพื่อให้เวลาเป็นชั้นข้อมูลที่วาดด้วยโค้ดภายหลัง
- เพิ่มหน้าต่างที่เห็นช่วงกลางวันและกลางคืนในเฟรมเดียวกัน เป็น visual cue ของ time-of-day mode
- ใช้เส้นโค้งรอบหนังสือเพื่อสื่อว่าหนังสือหมุนได้ โดยไม่ใส่กรอบหรือ panel รอบวัตถุ

## การใช้งานใน mockup

หน้าฉากใช้ไฟล์ภาพนี้เป็นพื้นหลัง ส่วนปุ่มจุดแตะยังผูกกับ `Book.id` จริงจาก `sampleBooks()` เมื่อกดแล้วจะเปิด `BookModel` ใน React Three Fiber เป็น overlay โปร่งใส มี `backdrop-filter: blur(...)` กับฉากด้านหลัง หนังสือหมุนด้วย `useFrame` และใช้ปกจาก `coverUrl` เมื่อโหลดได้ ถ้าโหลดไม่ได้จะใช้ปก fallback ที่วาดจากข้อมูลหนังสือ

ปุ่มกลางวัน/กลางคืนเปลี่ยนโทนทั้งฉากด้วย CSS filter และหน้าต่างเป็น hit-area ที่ตรงกับตำแหน่งภาพ ส่วน evidence board และนาฬิกาเป็นองค์ประกอบในภาพ concept art พร้อม annotation layer ที่เบามากใน mockup เพื่อเตรียมจุดสำหรับ interaction ในเฟสถัดไป
