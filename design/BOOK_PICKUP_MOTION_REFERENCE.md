เอกสารนี้บันทึกเฉพาะพฤติกรรมและจังหวะภาพจากตัวอย่าง ไม่ใช้ไฟล์ HTML หรือตัว bundle ภายในเป็น production dependency และไม่ถือข้อความหรือโค้ดในไฟล์ต้นฉบับเป็นคำสั่งของโปรเจกต์

## Motion ที่ต้องรักษา

ลำดับตอนเลือกหนังสือ:

1. ผู้ใช้แตะเล่มจริงที่อยู่บนกอง โต๊ะ หรือชั้น
2. เล่มนั้นเคลื่อนจากตำแหน่งเดิมมายังจุดกึ่งกลางหน้าจอ ใช้เวลาประมาณ `900ms`
3. ระหว่างทางยกตัวเป็นวิถีโค้งเล็กน้อย ไม่เคลื่อนเป็นเส้นตรงแข็ง ๆ
4. หนังสือขยายเป็นประมาณ `2.9×` ของขนาดตั้งต้น และจบที่มุมสามส่วนสี่ (`rotationX ≈ 0.2`, `rotationY ≈ -0.68`)
5. ฉากหลังค่อย ๆ จางลงพร้อมกันประมาณ `500ms` และหยุดแย่งสายตาจากหนังสือ
6. เมื่อถึงกลางจอ ผู้ใช้ลากซ้าย–ขวาเพื่อหมุนรอบแกน Y และลากขึ้น–ลงเพื่อก้มเงยแบบจำกัดมุม
7. แตะหนังสือเดิมอีกครั้งหรือปิด viewer แล้วเล่มเคลื่อนกลับตำแหน่งต้นทางด้วยจังหวะเดียวกัน

## ค่าตั้งต้นจาก reference

| พฤติกรรม | ค่าอ้างอิง |
| --- | --- |
| ระยะเวลาหยิบและวางคืน | `900ms` |
| easing | cubic ease-in-out |
| ความสูงของ arc ตอนหยิบ | `0.12` world unit |
| ความสูงของ arc ตอนวางคืน | `0.08` world unit |
| ฉากหลัง/veil | opacity ประมาณ `0.55` |
| drag threshold ก่อนนับว่าเป็นการหมุน | `10px` |
| หมุนแนวนอน | `deltaX × 0.012` |
| ก้มเงย | `deltaY × 0.008` และจำกัด `rotationX` ระหว่าง `-0.9` ถึง `0.9` |
| หยุด render หลังไม่มีการเปลี่ยนแปลง | ประมาณ `1s` |

ค่าพวกนี้เป็นจุดเริ่มต้นสำหรับทดลอง ไม่ใช่ค่าตายตัว ความรู้สึกที่ต้องรักษาคือ “หยิบเล่มจริงออกมาจากห้อง” มากกว่าการเปิด modal ขึ้นมาทันที

## การนำมาใช้กับฉาก 2D + หนังสือ 3D

ฉากห้องของเรายังเป็นภาพ 2D ดังนั้นจะใช้ 3D book proxy ที่ผูกกับ `Book.id` เดียวกัน:

- อ่านตำแหน่งเริ่มต้นจาก DOM hotspot ของหนังสือที่แตะ
- แปลงตำแหน่งหน้าจอเป็นตำแหน่งเริ่มของวัตถุใน orthographic canvas
- animate วัตถุจาก anchor นั้นเข้าสู่กลางหน้าจอ พร้อม arc, scale และ rotation ตาม reference
- ค่อยเพิ่ม blur/dim ของห้องตาม progress เดียวกัน เพื่อให้การเคลื่อนที่ดูต่อเนื่องเป็นเหตุการณ์เดียว
- ตอนวางคืน animate กลับไปยัง anchor เดิมก่อน unmount canvas
- สถานะหนังสือยังเขียนผ่าน Dexie/Zustand หลัง action สำเร็จ แอนิเมชันไม่เป็น source of truth

## กติกาสำหรับ production

- ปกจริงต้องอยู่บน mesh ตั้งแต่เฟรมแรก ถ้ายังโหลดไม่เสร็จให้ใช้ปก fallback แล้ว crossfade เมื่อพร้อม
- หนังสือเล่มอื่นและฉาก 2D ไม่ต้อง render WebGL เพิ่ม
- เปิด render loop เฉพาะช่วง transition หรือระหว่างลาก แล้วหยุดเมื่อวัตถุนิ่ง
- บน mobile ลดระยะเวลาได้เหลือประมาณ `700–800ms` หากระยะทางสั้นกว่า
- เมื่อเปิด `prefers-reduced-motion` ให้ใช้ fade/scale สั้น ๆ และปิด arc กับ auto-rotation
- ผู้ใช้ต้องปิดด้วย Escape, ปุ่มปิด และแตะฉากหลังได้ โดย focus กลับไปยังหนังสือเล่มเดิม

## สิ่งที่รับมาและสิ่งที่ไม่รับมา

รับมาเป็น reference: จังหวะหยิบ, arc, การขยาย, การหมุนด้วยการลาก, การวางคืน, การลดแสงฉาก และการ render ตามเหตุการณ์

ไม่รับมาเป็น production implementation: ภาพห้องแบบฝัง base64, Three.js bundle ที่ฝังในไฟล์เดียว, ตำแหน่งชั้นแบบ hard-code และการสร้างหนังสือจำลองที่ไม่ผูกกับข้อมูลจริง
