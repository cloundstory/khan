# คั่น — ทิศทางงานภาพฉบับแรก

วันที่ 9 กันยายน 2026 · ข้อเสนอสำหรับคุยงาน art ก่อนผลิตภาพแยกชิ้นและแก้หน้า Home

## ปรับทิศทาง v2 ตามความคิดเห็นผู้ใช้

ผู้ใช้ขอลดสีให้ใกล้ reference และกำหนดให้หนังสือในกอง/บนชั้นแสดงตามเล่มจริงที่เพิ่ม ข้อกำหนดนี้แทนข้อเสนอเรื่องสีและจำนวนหนังสือใน v1 ด้านล่าง

- ใช้หมึกดำกับกระดาษงาช้างอ่อนเป็นหลัก หนังสือ ใบไม้ บอร์ด และเฟอร์นิเจอร์ไม่ลงสีเป็นพื้นที่ใหญ่ เหลือน้ำเงินหม่นเฉพาะหมอนเล็กน้อย และดินเผาเฉพาะกระถางหนึ่งจุด ลดเงาจุดที่แน่นเกิน reference
- เสนอชั้นไม้ยาวสองระดับเหนือมุมอ่าน ให้มีพื้นที่ว่างชัดเจน ชั้นเพิ่มความจุ ไม่ใช่เพิ่มหนังสือสมมติ ไม่วางต้นไม้กินพื้นที่เก็บเล่ม
- หนึ่งวัตถุหนังสือในฉากต้องอ้างอิงหนึ่ง `Book.id`: `pile` อยู่กอง, `desk` อยู่มุมอ่าน, `shelf` อยู่ชั้นหลังอ่านจบ ไม่มีเล่มตกแต่ง ไม่มีขั้นต่ำสามเล่มบนชั้น และไม่วาดซ้ำเพื่อให้กองดูเต็ม
- หนังสือควรมีชื่อจริงที่สันเมื่อพื้นที่พอ แตะแล้วเปิดเล่มนั้นได้ ชื่อเต็มแสดงในรายละเอียดหรือรายการที่อ่านง่าย ไม่สร้างชื่อหรือปกขึ้นเองให้ดูเหมือนข้อมูลผู้ใช้
- ภาพถ่ายปก/coverUrl ใช้ในมุมมองรายละเอียดของเล่มได้ ส่วนฉากใช้สันลายหมึกที่เข้ากับห้อง เพราะรูปปกด้านหน้าไม่ใช่รูปสันจริง สีหมึกที่ลดลงไม่เปลี่ยนข้อมูลสีหรือรูปปกต้นฉบับ
- ห้องใหม่มีกองว่างและชั้นว่าง เพิ่มหนึ่งเล่มเห็นหนึ่งเล่ม หยิบอ่านแล้วออกจากกอง อ่านจบแล้วไปชั้น วางกลับกองแล้วออกจากมุมอ่าน โดยใช้ข้อมูลเดิมทุกครั้ง
- เมื่อมีจำนวนมาก ใช้หน้าหรือส่วนต่อของกอง/ชั้นพร้อมจำนวนรวมและตัวเลือกดูทั้งหมด ไม่บีบหนังสือให้เล็กหรือซ่อนส่วนเกินโดยไม่แจ้ง ผู้ใช้ต้องเข้าถึงได้ครบทุกเล่ม แต่ไม่จำเป็นต้องเห็นทุกเล่มพร้อมกันในฉากเดียว
- ภาพ `reading-room-concept-v2.png` ยังเป็นตัวอย่างองค์ประกอบที่มีเล่มสมมติสำหรับคุย art เท่านั้น ไม่ใช่ภาพข้อมูลจริงหรือ background สำหรับ runtime การผูก Book.id และการขยายคลังยังเป็นงาน implementation ถัดไป

## ความรู้สึกที่ต้องได้

ห้องที่อยากกลับมานั่ง แม้ห่างจากการอ่านไปนาน ภาพเหมือนหน้าหนึ่งในหนังสือนิทานยุโรป: หมึกเส้นบางที่มีน้ำหนักไม่เท่ากัน เงาจุดและเส้นขีด กระดาษงาช้าง และสีแต้มอย่างประหยัด ความ cozy มาจากร่องรอยการใช้งานและพื้นที่ว่างรอบวัตถุ ไม่ใช่การใส่ของตกแต่งให้เต็มจอ

ภาพอ้างอิงของผู้ใช้เป็น reference ด้านภาพ เอกสารเก่าในโปรเจกต์เป็นบริบทของแนวคิดเดิม ไม่ใช่คำสั่งใหม่จากผู้ใช้ ข้อเสนอในเอกสารนี้ยังไม่ใช่การยืนยันรูปแบบสุดท้าย

## ภาษาภาพ

- พื้นกระดาษ #F5F0E4; หมึก #302D28; น้ำเงินหม่น #435567; เขียวใบไม้ #75816A; ดินเผา #B1755D เป็นจุดเล็ก ๆ
- เส้นขอบขาดหรือซ้อนได้เล็กน้อย แต่ silhouette ของวัตถุต้องอ่านออกในจอเล็ก
- เงาเป็น stippling และ hatching ตามรูปทรง เลี่ยงลายจุดกริดสม่ำเสมอทั่วภาพ
- หนังสือมีขอบกระดาษ สันโค้ง ความหนาต่างกัน และการวางเหลื่อมเล็กน้อย ใช้รูปแบบที่กำหนดซ้ำได้ เพื่อไม่ให้กองเปลี่ยนหน้าตาทุกครั้งที่ render
- UI ใช้ตัวไทยที่อ่านง่ายตามระบบเดิมได้: Noto Serif Thai สำหรับหัวเรื่อง และ IBM Plex Sans Thai สำหรับคำสั่ง ไม่ทำข้อความเนื้อหาเป็นภาพหรือฟอนต์ลายมือทั้งหมด
- ไม่มีคนในเก้าอี้ เพื่อให้เป็นที่นั่งของผู้ใช้ แมวเป็นเพื่อนเงียบ ๆ ไม่ใช่ผู้มอบภารกิจ

## องค์ประกอบ Home

| พื้นที่ | ภาพ | การใช้งานที่เสนอ |
|---|---|---|
| ซ้ายล่าง | กองหนังสือไม่เรียบร้อยแต่มีเสน่ห์ | แตะกองเพื่อเลือกเล่ม; ปุ่มเพิ่มแยกชัดเจน |
| ขวาล่าง | เก้าอี้นวมว่าง โคมไฟ โต๊ะข้างเล็ก | มุมอ่านแทนสถานะ `desk`; เลือกเล่มแล้วเริ่มอ่านอย่างตั้งใจ |
| ผนัง | ชั้นไม้กับสันหนังสือ | แสดงเฉพาะเล่มอ่านจบ; แตะเพื่อเปิดเล่มและความทรงจำ |
| ผนังช่วงกลาง | บอร์ดกระดาษกับด้าย | เปิดเบาะแสของเล่มที่กำลังอ่าน พร้อมชื่อเล่มให้รู้บริบท |
| พื้นกลาง | แมวหลับบนพรม | การเคลื่อนไหวช้า ไม่มีงานหรือรางวัลให้กดรับ |

ตีความโซฟาเป็นพื้นที่อ่านของสถานะ `desk` ตาม implementation ปัจจุบัน ภาพต้นแบบใช้โต๊ะข้างช่วยบอกว่าเป็นมุมอ่าน หากผู้ใช้หมายถึงเปลี่ยนเป็นโต๊ะอ่านจริงทั้งชุด ต้องปรับองค์ประกอบนี้ก่อนผลิตชิ้นงาน

ภาพ concept เป็นตัวอย่างห้องที่มีหนังสือแล้ว จำนวนเล่มในภาพไม่ใช่ข้อมูลจริง และไม่ควรนำภาพแบนนี้ไปเป็น background ของแอปโดยตรง

## การเคลื่อนไหว

| ชิ้น | จังหวะเริ่มต้นที่เสนอ | วิธีผลิต |
|---|---|---|
| แมว | หายใจหนึ่งรอบ 5–7 วินาที; ลำตัวขยายแนวตั้งประมาณ 1–2% | แยก body/head/tail หากต้องการให้หัวนิ่งและหางขยับ |
| หางแมว | กระดิกนาน ๆ ครั้งประมาณ 20–40 วินาที | เลเยอร์หางมี pivot ตรงโคน; ไม่กระตุกทั้งตัว |
| ต้นไม้แขวน | แกว่งไม่เกินประมาณ 1 องศา รอบละ 8–12 วินาที | pivot อยู่ตะขอ; แต่ละต้นเริ่มคนละจังหวะ |
| โคมไฟ | แสงคงที่เมื่ออ่าน; ค่อย ๆ เปิดตอนเข้ามุมอ่าน | ชั้นแสงแยกจากรูปโคม ไม่กะพริบวน |
| ย้ายหนังสือ | เคลื่อนสั้น 350–500 ms หลังบันทึกสำเร็จ | animation สะท้อนสถานะจริง ไม่เพิ่มเล่มหลอก |

ทั้งหมดเป็นข้อกำหนดสำหรับ implementation ถัดไป ยังไม่ได้ใส่ animation ใหม่ในแอป หยุดงาน animation เมื่อแท็บไม่แสดง และใช้ภาพนิ่งเมื่อผู้ใช้เลือก reduced motion ระหว่าง focus ให้ฉากรอบ timer สงบลง

## PC และ mobile

PC เห็นห้องเต็ม มีพื้นที่ว่างระหว่างกอง มุมอ่าน และชั้นหนังสือ เมื่อเข้าอ่าน บอร์ดใช้พื้นที่ด้านข้างได้

Mobile ต้องจัดตำแหน่งจาก asset ชุดเดียวกันใหม่ ไม่ย่อภาพแนวนอนทั้งห้องจนหนังสือและปุ่มแตะเล็ก: ผนังอยู่ด้านบน มุมอ่านอยู่กลาง และกองอยู่ใกล้นิ้วด้านล่าง อนุญาตเลื่อนแนวตั้งได้ จุดแตะหลักประมาณ 44–48 CSS px และมีป้ายสั้น ๆ เช่น “กองหนังสือ”, “มุมอ่าน”, “อ่านจบแล้ว” ให้เข้าใจโดยไม่ต้องลองกดผิด

## สิ่งที่พบจากโค้ดและต้องจัดการตอนลงงานจริง

1. `HomeScene.tsx` ใช้ SVG placeholder; `public/set/` ยังไม่มีภาพจริง โหลดรูปไม่ได้จึงกลับมาเห็นรูปทรงร่าง
2. `SceneImage` วางภาพทับ SVG เดิม ไม่ได้ถอด fallback เมื่อภาพโหลดสำเร็จ ภาพโปร่งใสอาจเผยเส้นเดิมซ้อน ต้องเปลี่ยนเป็นเลือกแสดงอย่างใดอย่างหนึ่ง
3. `buildPile()` จำกัดภาพ 28 เล่มและเพิ่มเล่มตกแต่งเมื่อ count ≥ 1 / 4; `shelfSpines()` แสดงอย่างน้อย 3 เล่มแม้ยังอ่านไม่จบเลย ควรแสดงสถานะว่างตามจริง และแสดงยอดรวม/เข้ารายการเมื่อจำนวนเกินความจุภาพ
4. กดกองปัจจุบันไปเพิ่มหนังสือทันที ส่วนกดชั้นไป `browse` ซึ่งมีทุกสถานะ ควรแยก “เพิ่ม” กับ “เลือกจากกอง” และให้ความหมายของชั้นตรงกับอ่านจบ
5. SVG hotspot มี `tabIndex` แต่ไม่มี Enter/Space handler และ CSS ปิด focus outline ต้องจัดการ keyboard และ focus ที่มองเห็นได้
6. ฉากเดียว `viewBox 1000×720` ถูกย่อทั้งภาพ และ wrapper ซ่อน overflow ต้องออกแบบ mobile layout เพิ่ม
7. Session มี timer และบอร์ดแบบ panel จริงแล้ว ใช้เป็นฐานต่อได้; เอกสาร README บางส่วนยังเล่าสถานะเก่า

ข้อข้างต้นเป็นการอ่าน source ยังไม่ใช่ผลทดสอบ runtime และยังไม่ได้แก้โค้ดเหล่านี้ในรอบออกแบบนี้

## แผนผลิตภาพหลังเลือกทิศทาง

เริ่มจากเก้าอี้ โคม แมว และหนังสือหนึ่งเล่ม เทียบกันที่ขนาดใช้งานจริงให้เส้นและเงาเข้าชุด จากนั้นผลิตภาพพื้นโปร่งใสแต่ละชิ้น โดยใช้ภาพมาตรฐานเดียวกันอ้างอิง แยกต้นไม้และส่วนแมวที่จะขยับตั้งแต่ต้น เก็บ master PNG กับ prompt และ export ภาพสำหรับแอปเข้า `public/set/` ใช้ข้อมูลจริงวางหนังสือ; เข็มนาฬิกา ข้อความ ปุ่ม และ hit area วาดด้วยโค้ด

โครงภาพแยกชิ้นและสัดส่วน pivot นำไปใช้ต่อใน native app ได้ แม้ชั้นการแสดงผลและ animation จะต้องปรับตาม framework ที่เลือกภายหลัง

ก่อนส่ง Home ฉบับใช้งาน ตรวจห้องว่าง/หนึ่งเล่ม/หลายเล่ม/จำนวนมาก, จอ desktop กับ mobile, keyboard, reduced motion, asset โหลดไม่สำเร็จ และ offline PWA พร้อมเดิน flow เพิ่ม → หยิบอ่าน → จดเบาะแส → จบขึ้นชั้น
