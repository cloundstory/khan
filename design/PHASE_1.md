# เฟส 1 — สมุดทดลองภาพและหนังสือจริง

เริ่ม 9 กันยายน 2026 · สถานะ: มีต้นแบบทดลองวัสดุและความหนาแน่นแล้ว ยังไม่ล็อก art ทั้งห้อง

## เปิดทดลอง

รัน `npm run dev` ในโฟลเดอร์ khan แล้วเปิด `http://127.0.0.1:5173/?art-lab` (บน production base เดิม: `/khan/?art-lab`)

หน้าอ่านหลักยังอยู่ URL เดิม สมุดทดลองโหลดแยกด้วย lazy import ใช้ state ในแท็บเท่านั้น ไม่มีคำสั่งเขียน books/sessions หรือเปลี่ยนสถานะการอ่านจริง การเลือก “สำเนาคลังของฉัน” อ่าน IndexedDB ของ origin ปัจจุบัน จึงไม่เห็นคลังจาก URL/เบราว์เซอร์อื่นโดยอัตโนมัติ

## เครื่องมือที่เลือก

- imagegen ที่มีอยู่: ผลิต/ปรับภาพ raster และ master สำหรับภาพแยกเลเยอร์ ภาพ v2 จากรอบก่อนเป็น reference ในสมุดทดลองนี้ ไม่มีการผลิตภาพใหม่ในรอบนี้
- React Three Fiber จาก Game Studio: ใช้แนวทางแยก Canvas, data state และ DOM controls โครงการใช้ React 18 จึงติดตั้ง Fiber 8 พร้อม Three.js และ types ไม่เพิ่มระบบ physics หรือ postprocessing ที่ยังไม่จำเป็น
- เครื่องมือ browser ที่มีอยู่: ตรวจ interaction, ปกจริง และ responsive layout
- plugin-management: ตรวจความจำเป็นแล้ว ไม่ต้องเชื่อมบริการหรือติดตั้ง plugin เพิ่มเพื่อเริ่มงานนี้ ไลบรารี npm สำหรับ prototype เป็นคนละอย่างกับ Codex plugin

อ้างอิงเทคนิค: https://r3f.docs.pmnd.rs/getting-started/installation · https://r3f.docs.pmnd.rs/api/canvas · https://threejs.org/docs/pages/CanvasTexture.html

## สิ่งที่ทดลองได้แล้ว

1. ปกจริงบน front plane ของหนังสือ 3D พร้อมความหนา ขอบกระดาษ สัน และเส้นขอบ geometry
2. รักษาสัดส่วนภาพปกด้วย contain ไม่ตัดชื่อและไม่ยืดปกไปเป็นสัน ใช้ material ที่ไม่เปลี่ยนสีหน้าปกตามแสง ส่วนตัวเล่ม/ชั้นใช้วัสดุด้าน
3. เลือกเล่มด้วย pointer หรือรายการ DOM และปรับมุมของเล่มที่เลือก มีที่คั่นสีหม่นแสดง selection
4. ห้องว่าง / ตัวอย่าง 6 เล่ม / stress fixture 36 เล่ม แบ่งฉากละไม่เกิน 18 รายการ มีรายการรวมให้เข้าถึงทุกเล่ม โหมด 36 เล่มใช้ปกสามแบบซ้ำและมี ID แยกเพื่อทดสอบ ไม่ใช่คลังจริง 36 ชื่อ
5. ย้ายเล่มจากกอง → มุมอ่าน → ชั้น ใน state ทดลอง โดย ID เดิมอยู่เพียงตำแหน่งเดียว
6. ลองรูปปกจากเครื่องผ่าน object URL ในแท็บ ไม่ส่งออกหรือบันทึกลงคลัง มี fallback ชื่อเมื่อปกโหลดไม่ได้ และสลับภาพแบนได้
7. Desktop ใช้ฉากกับรายละเอียดข้างกัน Mobile วางต่อกันแนวตั้ง ปรับกล้องและความกว้างชั้นในโหมดมือถือ

## ข้อค้นพบจากต้นแบบ

- ปกสีจริงอ่านได้บนพื้นกระดาษอุ่น และสามารถคงภาพเต็มโดยไม่กรองสีต้นฉบับ
- Three.js สามารถใช้หนังสือทรงเรียบพร้อมภาพปกได้ ไม่จำเป็นต้องสร้างโมเดลด้วย AI ทีละชื่อ
- รูปทรง geometry และเงาปัจจุบันยังเรียบเกิน ref งานต่อคือเส้นที่มีน้ำหนัก ผิวขอบกระดาษ และเงาสัมผัสที่ละเอียด ไม่ควรประกาศว่าภาพ 3D เข้าชุดกับห้องแล้ว
- หนังสือบนชั้นในต้นแบบหันหน้าปกออกเพื่อทดสอบ texture ก่อน รุ่นองค์ประกอบจริงต้องเปรียบเทียบ “สันเป็นหลัก” กับ “โชว์ปกบางเล่ม” เพื่อลดน้ำหนักสีและเพิ่มความจุ
- แยกปกจริงออกจากสันและขอบเล่มได้ แต่สันตอนนี้ยังไม่มีชื่อจริงวาดลง texture ต้องทำต่อพร้อมระบบความกว้างสัน
- ตัวเลือกมือถือเป็น layout study ไม่ใช่ผล benchmark บนโทรศัพท์จริง ไม่มีการสรุป FPS/แบตเตอรี่จาก desktop viewport

## ข้อกำหนดองค์ประกอบสำหรับงานถัดไปในเฟส 1

Desktop: กองล่างซ้ายถ่วงมุมอ่านขวา แมวเป็นจุดเชื่อมพื้น โคมคั่นช่องว่างกลาง ชั้นสองระดับอยู่เหนือเก้าอี้ บอร์ดอยู่ผนังกลางซ้าย มีพื้นที่ว่างไม่ให้เส้นของโคม/ชั้น/ต้นไม้ชนกัน

Mobile: จัดจากชิ้นภาพเดียวกันใหม่ ผนังและชั้นอยู่ช่วงบน มุมอ่านเป็นจุดหลักช่วงกลาง กองและปุ่มเลือกเล่มอยู่ล่าง ไม่ใช้การ crop ภาพ desktop เป็นคำตอบสุดท้าย รายละเอียดเล่มเปิดในพื้นที่ DOM ที่อ่านง่าย

ต้องเทียบทั้งสองขนาดในสามสถานะ:

| สถานะ | สิ่งที่ต้องตรวจ |
|---|---|
| ว่าง | ห้องยังอบอุ่นโดยไม่ต้องเติมเล่มหลอก ปุ่มเพิ่มหาเจอ ชั้นไม่กลายเป็นพื้นที่รกร้าง |
| ใช้งานทั่วไป | เล่มที่กำลังอ่านเด่นพอ ปกสีไม่แย่งกับหมอน ทุกโซนอ่านออก |
| หนังสือมาก | กองไม่บังบอร์ด ชั้นไม่บังต้นไม้ จำนวนรวมและส่วนต่อชัดเจน ไม่มีเล่มหาย |

## เกณฑ์ปิดเฟส 1 ที่ยังต้องทำ

- ประกอบหนังสือ 3D เข้ากับภาพห้องที่ไม่มีหนังสือ baked-in ใน desktop/mobile composition จริง
- เลือก camera angle และวิธีแสดงสัน เทียบกับการโชว์ปก รวมถึงภาพปกไทยหลากหลายลักษณะ
- ล็อก line weight, hatch/stipple, palette และขอบกระดาษบนหนังสือหนึ่งเล่มกับเก้าอี้หนึ่งตัวที่ขนาดใช้งานจริง
- เทียบห้องสามสถานะครบทั้งสองรูปแบบก่อนเริ่มผลิต asset จำนวนมากในเฟส 2

## การตรวจรอบนี้

- TypeScript และ production build ผ่าน
- Vitest 35 tests ผ่าน รวม pagination: ห้องว่าง, 101 identities ข้ามหลายหน้าไม่หาย/ซ้ำ, เปลี่ยนกลับเป็นชุดเล็กแล้ว page ไม่ค้าง
- Browser ตรวจ WebGL แสดงปกจริงบนเล่ม, ปุ่มย้ายขึ้นชั้น, fixture 36 เล่มและหน้าที่สอง, ห้องว่าง, layout มือถือ 390×844 (พื้นที่ content 375 px ไม่ล้นแนวนอน)
- พบและแก้ fallback ที่ถูกเรียกแม้ Canvas ใช้งานได้ และการเปลี่ยน material จากไม่มี map เป็น texture แล้วไม่ rebuild shader
- ยังไม่ได้ทดสอบโทรศัพท์จริง, upload ผ่าน file picker, ปกถ่ายเองในคลังที่มีข้อมูล, offline install หรือ GPU context loss
- Console มี Three.Clock deprecation จาก Fiber 8 ไม่มี error ระหว่างตรวจหลังแก้ ไม่เปลี่ยน React major เพื่อแก้ warning ในเฟส art
- BookStudy bundle ประมาณ 888 kB ก่อน gzip และภาพ reference ประมาณ 2.7 MB โหลดเฉพาะหน้าทดลอง; ยกเว้นจาก PWA precache ไม่เพิ่มภาระติดตั้งหลัก งาน production ยังต้องลด texture/asset และทดสอบอุปกรณ์จริง
